# 🎲 Random Cube

Реалистичный 3D-кубик в браузере: случайное число от 1 до N.

- Чистый HTML, CSS и JavaScript, без библиотек, шрифтов и CDN, работает офлайн.
- 3D на CSS-трансформациях, физика броска (подскоки, перекат по рёбрам), динамический свет и тень.
- В покое сайт не тратит ресурсы: анимация считается только во время броска.
- N от 1 до 1 000 000: при N ≤ 6 на гранях точки, при N > 6 цифры.
- Звук удара синтезируется на лету через Web Audio, без аудиофайлов.
- Честный аналог `random.randint` на `crypto.getRandomValues`, без перекоса.
- История бросков, статистика, три материала кубика, поддержка `prefers-reduced-motion`.

Управление: **Space**, клик по кубику или кнопка «Бросить». **Enter** в поле N тоже бросает, **M** включает и выключает звук.

## Python-версия

```bash
python random_cube.py
```

## Публикация на GitHub Pages

1. Загрузите все файлы в корень репозитория (ветка `main`).
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Локально можно просто открыть `index.html` двойным кликом.
